# 续航便签 v0.3.0 实施约定

用户选择“续航便签”，授权将卡片与九号车联集成放在同一个项目、随包安装和更新。只实现这一种布局，不增加车辆控制、轨迹、AI或新的九号请求。

主视图包含车辆名、独立开机状态、大号电量、精准预计续航、充电状态、电量条、区域和各自上报时间。电池详情默认折叠，按返回槽位展示电压、温度、电量、明确支持的循环次数及接口评分（非SOH），另外显示电池查询时间。未知与不可用分开提示，不补零，不把ACC或主电池在线当作行驶/整车电源。上报过旧保留数值并标记，上报时间不得以查询时间替代。

配置以device_id选择车辆，允许entities按角色显式覆盖；可配置标题、位置和电池详情显示。实体角色由集成提供不含隐私的ninebot_connect_role属性，避免依赖可被用户重命名或翻译的entity_id。自动发现必须限制在所选设备，不得串车；可视化编辑器与YAML配置均可用。点击数值发出HA more-info事件，不发送服务或控车命令。

卡片使用原生Web Component，不加载CDN或运行时第三方库。静态模板可使用innerHTML，所有实体名、状态、配置等动态值必须使用textContent或安全DOM属性。跟随HA主题，支持320px起的手机宽度、Sections和Masonry。折叠状态在实体更新后保持；相对时间定时更新，卸载时清理计时器。Sections使用auto高度，Masonry通过getCardSize提供实际尺寸及未挂载时的估计，不依赖未公开的尺寸事件。

资源位于custom_components/ninebot_connect/frontend内，仅注册明确的JS文件路径；集成目录、令牌和其他文件不对外开放。静态资源按HA生命周期只注册一次。正常Storage资源模式自动添加或更新此项目自己的模块资源，不修改用户仪表盘；YAML资源模式提供手动配置，不改用户YAML。多账号、重载和浏览器缓存均须处理。前端安装失败不影响已有车况实体。

验证边界沿用已批准的HA配置/实体及卡片公开接口：实际浏览器中的setConfig/hass更新、实体发现、槽位变化、点击事件、编辑器、状态缺失、注入防护、折叠持久与窄屏；HA静态文件和Lovelace资源集合；ZIP允许列表。浏览器用合成状态，明确区分本机组件测试与用户HA实际安装。
